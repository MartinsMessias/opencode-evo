Spawns multiple subagents concurrently (Swarm) to drastically reduce overall execution time for parallelizeable tasks.

Use this tool when the user requests multiple independent goals (e.g. "Migrate the database and adjust the frontend UI" or "Fix the API and write tests for it"). The orchestrator (you) will delegate the work to specialized subagents that will operate completely simultaneously. 

IMPORTANT: For simpler or heavily scoped tasks (e.g. a small formatting change in a single file), you can explicitly request a cheaper or faster model on the specific task to save cost, such as "@ai-sdk/anthropic/claude-3-haiku-20240307".
